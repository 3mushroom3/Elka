# Ёлка: как запустить проект на новом компьютере

Инструкция для Claude Code. Если пользователь просит «запусти проект», действуй по ней.

## Что нужно на машине

- Node.js 24 и npm 11 (проверка: `node -v`, `npm -v`). Проект собирался на Node 24.19, npm 11.17.
- Git.
- Отдельно ставить PostgreSQL или Docker не нужно: база встроенная, приходит вместе с `npm install`.

## Первый запуск

```
git clone https://github.com/3mushroom3/Elka.git
cd Elka
npm install
copy .env.example .env
npm run dev
```

На macOS и Linux вместо `copy` используй `cp`.

`npm run dev` (это `scripts/dev.ts`) сам:

1. поднимает встроенный PostgreSQL на порту 54329, данные кладёт в `.pgdata`;
2. применяет миграции (`prisma migrate deploy`);
3. создаёт менеджера и справочник видов товара (`prisma/seed.ts`);
4. запускает сайт на http://localhost:3000.

Первый вход: логин `admin`, пароль `admin12345`.

Запускай `npm run dev` в фоне и проверяй готовность запросом к `http://localhost:3000/login` (должен вернуть 200).
Первая компиляция страницы занимает до минуты.

## База на новой машине пустая

Папка `.pgdata` в git не попадает, поэтому данные с другого компьютера не переносятся:
после первого запуска есть только `admin` и справочник видов.

Учебные данные (точки, сотрудники, завозы, смены, продажи) добавляются только в пустую базу,
при запущенной базе:

```
npx tsx scripts/demo-data.ts
```

## Перед запуском проверь, не запущено ли уже

Порты 3000 (сайт) и 54329 (база). Если оба заняты процессами этого проекта и сайт отвечает,
второй экземпляр поднимать не нужно. Если база уже работает, `npm run dev` подхватит её сам.

## Известные сбои

**`Can't reach database server at localhost:54329`, хотя порт занят.** База зависла: соединение
принимает, на запросы не отвечает. Останови её штатно и запусти проект заново:

```
node_modules\@embedded-postgres\windows-x64\native\bin\pg_ctl.exe stop -D .pgdata -m fast
npm run dev
```

На других системах вместо `windows-x64` будет папка своей платформы. Не убивай `postgres`
принудительно, пока не попробовал `pg_ctl stop`.

**`Jest worker encountered 2 child process exceptions`.** Упал служебный процесс dev-сервера Next.
Останови процессы `next dev` и `scripts/dev.ts`, затем снова `npm run dev`. Базу трогать не нужно.

## Прочее
